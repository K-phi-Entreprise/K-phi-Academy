# Phase 0: decisions to approve

K-φ Certified Builder. One page. Each line has a proposed default; reply with the numbers you want changed.

## Names and badges

1. **Programme name:** K-φ Academy. **Credentials (decided 8 Nov):** AI-Ready Finance Practitioner and AI-Ready Finance Consultant, certified by K-φ.
2. **Paths:** every path starts with Foundation and AI for finance. Practitioner = those two (4 h); Practitioner · FP&A, · Cash or · Build adds one course (8 h); **AI-Ready Finance Consultant** = all six courses, including Implementation (18 h).
3. **Founding cohort:** the pilot group is numbered "Founding Builder #1 to #5". The title is permanent and carries no financial rights.

## Pass rules

4. **Figures:** within 0.5% or 1 unit of the answer key, whichever is larger, per checked value.
5. **Write-back (Cash and Build):** amount, sign, value date and target account all correct. No tolerance on sign or date.
6. **Governance:** the task must respect roles and dual control. A change that bypassed an approver is an automatic fail, whatever the figures.
7. **Trap:** each module has one seeded trap. Missing it is a fail. Catching it but explaining it wrong is a pass with a note.
8. **Attempts:** three attempts per module, at least 24 hours apart. Each attempt gets a fresh tenant with slightly varied data.

## Validity and revocation

9. **Validity:** 12 months, tied to a platform version. Renewal is a short re-test on the current version.
10. **Revocation:** for misrepresenting the credential, sharing exam answers, or work in a client tenant that breaks the governance rules taught in module 0. The verify page then shows "revoked", with no reason given publicly.

## Independence

11. Certified builders hold no equity, shares or stake in K-φ, and K-φ pays them no referral fee.
12. Any revenue a builder earns from extensions they publish is disclosed on their verify page.
13. Certification means verified skill and a directory listing. It never means leads, work or ownership of the IP built on K-φ.

## Cost and access

14. **Pilot:** free, by invitation, five consultants chosen by Vincent.
15. **After the pilot:** free for consultants, by invite code, capped at 50. Paid for client staff (price to be set later).
16. **Tools:** candidates use any LLM (Claude, Codex, Gemini CLI). Only the result in the tenant is graded.

## Public surface

17. **Course and verify pages** at `academy.k-phi.com`. Course pages are public and indexable.
18. **Directory:** active certificates only, opt-out possible for the holder.
19. **Published pass rate:** per module, updated each quarter once there are at least 20 attempts.

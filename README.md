# K-φ Academy

Courses and certification for K-φ: Foundation, FP&A, Cash, Build, Implementation.

- `site/` lesson content (`content_*.py`) and the page template. `python3 site/build.py` writes `site/dist/`.
- `docs/` the plan, the Phase 0 decisions and the structure of the academy.
- Published on GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

Exams, answer keys and checkers live in the private repo `K-phi-certify`, never here.
